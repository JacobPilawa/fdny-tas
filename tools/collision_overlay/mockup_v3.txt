FDNY collision-warp overlay -- mockup v3 (approved and built, 2026-10-16)

Changes from v2 (owner feedback: "Last frame" not helpful, WARP WINDOW lines
confusing, "IF YOU WARP NOW" just mirrors the player's coords when in bounds):

  - PLAYER, WARP WINDOW and IF YOU WARP NOW merge into ONE box, WARP.
  - "Last frame" verdict is gone (a warp always fires when the conditions
    hold, so the only after-the-fact info worth showing is LAST WARP).
  - "Inside solid" / "Head above underside" / the 4-sweep line are gone from
    the overlay (still written to the log). Replaced by ONE plain status line
    that says what to do.
  - The warp target is only shown while you are inside solid. In bounds your
    own movement overwrites the slot every frame, so it would just be you.
  - LAST WARP and HISTORY unchanged.
